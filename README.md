## LinkdPaws

Linkdin clone but for animals. A social media platform for pet lovers to connect, share, and discover content related to their furry friends.


## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
